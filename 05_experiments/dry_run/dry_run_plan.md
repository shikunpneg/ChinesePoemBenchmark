# 4.1 · 一次试跑

## 目标

验证 AI4S 探索流程能否正常运行。**不是**为了得出科学结论。

## 输入

- 小型中文诗歌测试数据集（约正式规模的 1/5）
- 保留人工标注、数据划分、评价协议
- 第二阶段使用小规模 AI 生成诗歌数据集

## 步骤

1. 准备小规模数据（落到 `05_experiments/dry_run/data/`）
2. 启动 Harness（`07_reproducibility/scripts/` 待实现）
3. 第 1 阶段：基础评测指标组合探索（小预算）
4. 进入第 2 阶段：动态提高 AI 模仿相似度（小预算）
5. 由 Check-Agent 检查数据访问、规则执行、实验协议
6. 输出可用性测试报告到 `06_artifacts/reports/dry_run_report.md`

## 关键证据（必记录）

- [ ] 小规模数据集下能否找到趋于稳定的指标组合
- [ ] 一致性是否达到第 1 阶段预设阈值并进入第 2 阶段
- [ ] 第 2 阶段 AI 生成诗歌与目标人类诗歌相似度是否动态提升
- [ ] 自动评测指标与人类判断是否出现失效或不同步变化
- [ ] Check-Agent 是否发现并阻止越界操作
- [ ] 失败样本、异常结果与 Agent 决策过程是否被完整记录
