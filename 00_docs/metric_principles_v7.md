## 1. meter 族（7 个）—— 近体诗格律标准【新，阶段 A】

**设计依据**：古典诗（近体诗/绝句/律诗）的格律有**严格标准**，不是「行数相等」。我们实现了真实规则。

### 1.1 平仄判定
```
pypinyin 得到每字声调(1-5)：
  现代普通话近似：1,2 调 → 平；3,4 调 → 仄；5 调（轻声）→ 跳过
```
⚠️ **局限声明**：古典平仄基于**中古音（平水韵）**，现代声调只是近似。代码已留 `charset` 钩子，后续可接入平水韵表。

### 1.2 句式匹配（A/B/C/D 四式）
五言：
```
A: ⊙仄平平仄    平平仄仄平  (可平可仄⊙)
B: 平平仄仄平    平平仄仄平
C: ⊙平平仄仄    平平平仄仄
D: ⊙仄仄平平    仄仄仄平平
```
七言：在五言前加 `⊙平` / `⊙仄`。

`meter_line_pattern_ok` = 能匹配上 A/B/C/D 任一句式的行占比。

### 1.3 粘对（对仗规则的核心）
- **对**（dui）：奇数/偶数相邻行（1-2, 3-4, 5-6, 7-8）平仄**必须相反**
- **粘**（nian）：偶数行与下一奇数行（2-3, 4-5, 6-7）第 2 字平仄**必须相同**

`meter_dui_ok` = 1 − (违反「对」的位数占比)
`meter_nian_ok` = 1 − (违反「粘」的位数占比)

### 1.4 押韵（rhyme）
- 偶数行（2,4,6,8）必须同韵
- `rhyme_group`：由行末字拼音的**韵母**（去掉声母）分组
- `meter_rhyme_agreement` = 偶数行韵母一致的比例

⚠️ **局限**：现代拼音韵母近似平水韵韵部。

### 1.5 对仗（parallelism，律诗专有）
- 律诗 3/4 联、5/6 联必须对仗
- `meter_parallelism`：用 jieba.posseg 词性序列在**对称位置**的重合率（名词对名词、动词对动词）

### 1.6 合律判定
`meter_is_metrical` = (dui_ok ≥ 0.7) ∧ (nian_ok ≥ 0.7) ∧ (rhyme ≥ 0.5)

### 1.7 诗体判定
```
4 行 + 五/七言 → 绝句 (form_score=0.7)
8 行 + 五/七言 → 律诗 (form_score=1.0)
其他 → 非近体 (form_score=0.0)
```

## 2. struct 族（3 + 9 个）—— 结构 + 段落主题【新，阶段 B】

### 2.1 原 3 个（保留）
| 特征 | 原理 |
|---|---|
| `struct_n_lines` | 行数分段映射 |
| `struct_line_ending_punct` | 1 − 行末标点比例 |
| `struct_short_line_ratio` | 短行（≤14 汉字）占比 |

### 2.2 段落统计（新 4 个）
按**空行**分段落（无空行则退回按行分）：
| 特征 | 原理 |
|---|---|
| `para_para_count` | 段落数 |
| `para_para_len_mean` | 平均段长 / 60（诗~30，散文~100+） |
| `para_para_len_cv` | 段长变异系数 |
| `para_para_var` | 段长标准差 |

### 2.3 段落主题 NLP（新 5 个 + v8 语义单元 6 个）

**v7 每段用 jieba 提取内容词**（长度≥2 且非停用词），组成**关键词 TF 向量**：
| 特征 | 原理 |
|---|---|
| `theme_theme_jump_mean` | 相邻段落关键词向量的**余弦距离**均值（主题跳了多少） |
| `theme_theme_jump_cv` | 上述距离的变异系数（诗=中等变化，散文=低，随机=高） |
| `theme_theme_coherence` | 1 − 全局词频信息熵归一化（主题聚焦度） |
| `theme_theme_cluster_ratio` | 与首段共享≥1 个内容词的段落占比（主题持续性） |
| `theme_opening_closure` | 首段 vs 末段关键词向量余弦（首尾呼应） |

⚠️ **v7 已知局限**：短行古诗每段只有 1-2 个词，向量稀疏。

**v8 修复（theme8 族）**：`semantic_units()` 先把文本按空行/句末标点分段，再合并不足 12 字的段为语义单元：
| 特征 | 原理 |
|---|---|
| `theme8_theme_jump_mean` | 语义单元间的余弦距离均值（同 v7 但单元更密） |
| `theme8_theme_jump_cv` | 同上 CV |
| `theme8_theme_coherence` | 1 − 单元词频熵归一化 |
| `theme8_theme_cluster_ratio` | 与首单元共享词的单元占比 |
| `theme8_opening_closure` | 首/末单元余弦 |
| `theme8_unit_count_norm` | 语义单元数归一化（单元数/10，诗通常 2-4 单元） |

## 3. NER 意象族（9 个）—— 顺序逻辑分析【新，阶段 C】

### 3.1 实体/意象抽取
用 **jieba.posseg**（词性标注）识别：
- 名词/动词（n/nr/ns/nt/nz/v/vn/an/i）→ 实体
- 命中**意象词表**（`FIELD_WORDS`，7 个意象场：天象/山水/动物/季节/情感/感官/现代）→ 意象

### 3.2 意象场分类
每个意象词映射到一个**语义场**（如「月」→天象，「河」→山水）。

### 3.3 顺序逻辑分析（按文本从上到下）

**v7**：实体相似度用字符重叠。
**v8**：实体相似度用 **bge-small-zh 余弦**（解决「明月↔霜」无共同字问题；磁盘缓存 22201 个实体词，`entity_vec_cache.npz`）。

| 特征 | 原理 |
|---|---|
| `img_ent_adj_sim_mean` | 相邻实体的语义相似度均值（v8=bge 余弦） |
| `img_ent_adj_sim_cv` | 上述相似度变异系数 |
| `img_field_switch_rate` | 相邻实体**切换意象场**的比例（跳跃） |
| `img_field_return` | 返回**之前出现过**的意象场的比例（意象回环） |
| `img_rupture_bridge` | 低相似（v8 阈值 0.5）的相邻对中**共享意象场**的比例（断裂-引力） |
| `img_logic_jump_score` | 复合：断裂率 × (0.5 + 0.5×bridge) |

**v8 语义实证**：明月↔霜 = 0.406（bge），字符重叠 = 0——语义向量正确捕捉同属天象意象的关联。

## 4. phonetics 族（6 个）—— 真实声学信号【新，阶段 D】

**设计依据**（旧方案 §2 原则二）：
> 音乐性根植于实际发音而非文字表面。平仄=声调调值曲线，押韵=韵母音位距离。

### 4.1 调值曲线（五度标记）
每字声调映射到五度值：1调→5, 2调→4, 3调→2, 4调→1, 5调→3
```
tone_smoothness = 1 − (相邻调值差的均值 / 4)
tone_cv         = 调值序列的变异系数
```

### 4.2 元音开口度（共振代理）
拼音韵母 → 主元音 → 开口度等级：
```
i/ü/u → 1 (闭),  e/o → 2 (半闭),  ê → 3 (半开),  a/ɑ → 4 (开)
```
```
resonance_var = 开口度序列的变异系数映射（0.2-0.5 → 1.0 活跃）
```

### 4.3 韵母音位距离
```
rhyme_phoneme_distance(a, b):
  主元音不同 → +0.5 + 开口度差×0.1
  韵尾不同   → +0.3
```
验证：光(guang) vs 霜(shuang) = 0.0（同韵）✅；光 vs 河(he) = 1.0 ✅
```
rhyme_distance = 偶数行末字韵母距离均值（低=和谐）
rhyme_repeat   = 偶数行对中距离<0.2 的比例
```

### 4.4 平仄均衡
`tone_balance = 1 − |平/(平+仄) − 0.5| × 2`（真实调值判断，非字形）

## 5. semantic 族（6 个）—— bge-small-zh 语义向量【新，阶段 E】

**模型**：`BAAI/bge-small-zh-v1.5`（24M 参数，sentence-transformers）
**输入**：每行文本 → 384 维向量（批处理 + 磁盘缓存加速）

| 特征 | 原理 |
|---|---|
| `sem_adj_line_sim_mean` | 相邻行向量**余弦相似度**均值 |
| `sem_adj_line_sim_cv` | 上述相似度变异系数 |
| `sem_first_last_sim` | 首行 vs 末行余弦（首尾呼应） |
| `sem_bridge_rate` | 低相似（<0.3）的相邻对中，与**全诗质心**深度相关（>0.15）的比例（断裂-引力） |
| `sem_wholeness` | 0.4×邻行相似 + 0.3×bridge + 0.3×首尾呼应 |
| `sem_dispersion` | 1 − wholeness |

**实测区分度**：
| 文本 | adj_sim | first_last | wholeness |
|---|---|---|---|
| 静夜思（诗）| 0.40 | 0.30 | 0.55 |
| 新闻 | 0.53 | 0.51 | 0.66 |
| 顾城《小巷》| 0.48 | 0.42 | 0.62 |

⚠️ **注意**：新闻的 wholeness 反而高（语义连贯）——**语义指标单独不能区分诗/非诗**，需配合断裂-引力与格律。v7 实测语义特征对 LR 增益不明显（见 v7c vs v7b）。

## 7. v7 实测结果（R15）

| 版本 | 特征 | val Kappa | expert Kappa | AI 诗 Kappa | AI fp |
|---|---|---|---|---|---|
| v2 (冻结) | 21+5 | 0.930 | 0.940 | 0.032 | 31 |
| v7a | 58+5 | 0.930 | 0.940 | 0.032 | 31 |
| v7b (+AI neg) | 58+5 | **0.947** | 0.900 | 0.438 | **0** |
| v7c (无语义) | 52+5 | 0.947 | 0.880 | **0.481** | **0** |

**结论**：
1. 新特征（格律/段落/NER/语义/声学）**未显著提升 val Kappa**（0.947 vs v4b 0.974 反而略降）
2. **语义向量（bge）在 AI 诗集上无增益**（v7c 0.481 > v7b 0.438）——短诗行嵌入区分度不足
3. **v4b 仍是结构指标收敛点**——新特征族丰富了可解释性，但未突破性能
4. **新特征族的真正价值**在**可解释性**（格律合律度、意象场跳跃、韵母和谐度）——而非 kappa 提升
