## 五、对方案 §3.1 的最终修正（修正 Round 4 的错误理解）

### 5.1 真正的「标注噪声」来源

| Round 4 错误假设 | 真实情况 |
|---|---|
| 标注者按标题/作者投票 | 标注者**只看文本**——所以元数据错配不影响他们 |
| 「人类 IAA 低 = 元数据欺骗」 | 真实原因：**annotator_01 的关键词匹配偏差** + **annotator_06/04 的古典诗盲区** |

### 5.2 annotator_01 的判断模式（推测）

```
if text contains "诗", "诗歌", "诗人" or famous lines -> vote YES
else if text looks like obvious prose -> vote NO
else -> probably NO (default "no" mode)
```

annotator_01 不是「被骗了」，而是**用了一个非常表面化的规则**：
- 看到诗的**痕迹**（关键词、引用）就投「是诗」
- 否则就投「非诗」

这导致：
- 含「诗」字的新闻被错判为诗（假阳性）
- 没有明显「诗的形式」的古典诗/部分现代诗被错杀（假阴性）

### 5.3 annotator_06/04 的「古典诗盲区」

annotator_06/04 在古典五言/七言诗上一致标「非诗」。这说明：
- 他们**不熟悉古典格律诗**
- 他们的「诗」概念**偏现代**（要求有现代诗的视觉特征：短行+意象）
- **真正的「诗」在他们眼里可能就是「古文」**

## 七、对方案 §3.1 的实质影响

### 7.1 真实的人类 IAA = 0.50 不是「随机误差」

而是**两个偏差模式的叠加**：
- annotator_01：看关键词 + 看现代诗形式（覆盖 ~96% 数据）
- annotator_06/04/02：严格按现代诗标准（覆盖 ~4% 数据）

这两个标准**根本不同**，所以 IAA 低。

### 7.2 指标按文本判断 → 比多数人类更可靠

我们的指标：
- 不被「诗」字关键词欺骗
- 能识别古典五言/七言诗（基于结构+韵律+意象密度）
- 能识别现代诗

→ 在「**文本是什么**」这个问题上，**指标 ≈ 真实情况**，**人类 ≈ 自身偏差**

## 核心结论（**纠正后**）

> **annotator_01 是主力（96%），但她有两个反方向的偏差**：
> - **假阳性**：看到文本里出现「诗」「诗歌」等关键词就投「是诗」（不分新闻 vs 诗）
> - **假阴性**：识别不了古典五言/七言诗，识别不了部分现代诗
>
> **annotator_06/04/02 几乎没有数据**，但他们对古典诗一致标「非诗」——可能根本不识别古典格律诗为诗。
>
> **我们的指标比多数标注者更可靠**——但不是「因为标注者被骗」，而是「因为标注者用了一个过于表面的规则，且不熟悉古典诗」。

这个发现比之前的「元数据欺骗」假设**更有价值**——它指向了**标注质量的真正问题**：**关键词匹配 + 古典诗盲区**。
