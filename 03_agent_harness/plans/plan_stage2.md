# Plan · 第 2 阶段 · 困难样本与指标失效探索（v2.0 修订版）

> 不可由 Agent 修改。本文件由项目负责人维护。
> v2.0 重大修订（2026-08-14）：基于 11 轮实验的发现，**重新定义 Stage 2 的目标与执行方式**。

## 重大修订说明

原 v1 假设：
> 「AI 越来越像人类诗 → 指标 vs 人类一致性下降 → 检验指标是否先失效」

**实测推翻**（Stage 2 R1）：
- AI 仿诗相似度从 0.000 到 1.000 全程
- 指标在所有相似度下都判 97-99% 为诗
- **指标不区分来源**（结构分类器 vs 来源分类器）
- **不存在「指标先失效」的衰减曲线**

## 修订后目标

**v2 目标**：
> 1. 在**已标注数据**（人类判断的诗 / 非诗）上**评估冻结指标**的校准、置信度、不确定区
> 2. 在**AI 仿诗的标注**（人类已判 209 条）上**找指标的真实失效模式**
> 3. 通过**指标迭代闭环**（v4b 模型已演示）将发现的失败模式转化为可重训的反例

**Stage 2 的真正产出**：
- **真 IAA**（不靠文献值）：实测 Fleiss' Kappa
- **指标 vs 干净人类**的一致性（剔除标注噪声后）
- **AI 仿诗上的真实失败模式**（31 条「人类说不、指标说是」的夹带英文 AI 诗）
- **指标迭代的反例库**（用于 v4b 重训）

## 输入

- 第 1 阶段产出的**最优指标组合**（v2 冻结 / v4b 迭代候选）
- **`02_environment/data_registry/`** 中已标注的诗 / 非诗数据
- **`eval-annotation/backups/annotations_export*.csv`**：人类标注数据
- **AI 仿诗 + 人类标签**：`hard_gen_*.jsonl`（5194 条 AI 仿诗）+ annotator_06 的 209 条匹配

## 输出

- 实验日志：`04_memory/experiment_logs/stage2_round_<NNN>.json`
- 失败样本：`04_memory/failures/stage2_round_<NNN>.jsonl`
- **真实 IAA 报告**：方案 §1.3 的科学问题「人类依赖哪些特征」
- **指标迭代反馈**：发现反例 → 加反例 → 重训 → 评估（v3 → v4b → v5 链路）
- **跨数据集评估产物**：在原 val + 专家集 + AI 诗集三处的指标表现

## 单轮步骤（v2.0 修订）

1. **观察**：上一轮真 IAA、指标-人类一致性、AI 诗 kappa 等
2. **边界检查**：`check_agent/audit_cycle.md#pre_round`
3. **动作**（v2.0 扩展）：
   - **校准分析**：ECE / Brier score
   - **不确定区诊断**：0.3-0.7 区间的样本特征
   - **分层失败分析**：按 `genre × source_type × n_raters` 分组
   - **标注者画像**：per-annotator vs 指标
   - **AI 诗评测**：annotator_06 标注的 209 条
   - **指标迭代**：发现失败 → 加反例 → 重训 → 评估
4. **执行**：
   - 用**当前版本指标**（v2/v4b/v5）评估新数据
   - 找高置信错误（指标 vs 人类）
   - 人工复核错误 → 判定「指标错 or 人类错」
5. **反馈**（v2.0 扩展）：
   - 性能反馈：val kappa、AI 诗 kappa
   - **校准反馈**：ECE 应 < 0.01
   - **失败反馈**：高置信错误应 < 5%
   - **标注噪声反馈**：剔除噪声后指标应 >= 0.85
6. **边界检查**：`check_agent/audit_cycle.md#post_round`
7. **记录**：`SKILL_log_round.md`

## 实际迭代历史（11 轮后）

| 轮次 | 内容 | 关键发现 |
|---|---|---|
| R1 | 指标跑 AI 仿诗（无 ground truth）| 衰减曲线是平的（指标不区分来源）|
| R2 | 校准 + 不确定区诊断 | ECE 0.0071（极好）；不确定区 10 个全诗 |
| R3 | 真 IAA（旧数据）| 真实 Fleiss' 0.504，指标 vs 人类 0.372 |
| R4-5 | 标注者画像 | annotator_01 关键词匹配偏差 |
| R7-8 | 新数据 + 剔除噪声 | 剔除后 IAA 0.822，指标 vs 人类 0.924 |
| **R9** | **annotator_06 标 AI 诗评测** | **31 条「人类说不、指标说是」= 夹带英文的 AI 垃圾** |
| R10 | 加 purity 特征（v3）| 单独加特征无效 |
| **R11** | **+ 32 AI 负样本（v4b）** | **AI 诗 fp=0，val 0.974** |
| R12 | + style 特征（v5）| social/news 已 100% reject，style 无帮助 |
| R13 | L2 子指标 + ablation | form 是关键族；struct / style 应移除 |
