# 平凡解 / 随机 / 无干预 参照（对应方案 §3.2）

> 这三类参照是「判断 Agent 是否真正避免平凡效应」的唯一来源。

## 平凡解参照

| ID            | 名称       | 描述                                          |
| ------------- | ---------- | --------------------------------------------- |
| TR-bleu       | BLEU       | 直接对候选文本与人类参考文本做 n-gram 重叠       |
| TR-rouge      | ROUGE-L    | 最长公共子序列                                 |
| TR-single-len | single-length | 只用文本长度做分类                          |
| TR-single-ttr | single-ttr   | 只用类符/形符比做分类                       |

## 随机参照

| ID          | 名称       | 描述                                          |
| ----------- | ---------- | --------------------------------------------- |
| RN-rand-comb | random-combination | 从基础特征中随机抽样做组合             |
| RN-rand-label | random-label       | 对每条样本随机分配「诗歌/非诗歌」        |

> 随机参照用于在相同数据划分与评价协议下判断 Agent 探索是否显著高于随机水平。

## 无干预参照

| ID          | 名称       | 描述                                          |
| ----------- | ---------- | --------------------------------------------- |
| NV-fixed    | no-iteration | 固定初始指标组合与生成数据集，不做迭代优化   |

> 无干预参照用于判断多轮反馈闭环是否真的带来收益。

## 比较指标

- 与人类判断的一致性（主指标）
- 困难样本上的一致性
- 跨数据切片的稳定性
- 多轮实验后的性能变化

## 成立条件（方案 §3.2 末尾）

只有当 Agent 探索结果在独立验证数据上**稳定超过**以上三类参照，且提升不是由单一数据切片或偶然样本造成时，才能认为避免了平凡效应。
