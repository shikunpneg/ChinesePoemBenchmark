# 2.1 环境边界（固定规则）

> 本文件对应方案 §2.1。**不可修改规则**详见 `03_agent_harness/check_agent/rules.md`。

## 环境边界

Agent 只能使用**预先提供的数据集**和**基础评测特征**，不得擅自引入：

- 外部数据
- 未定义的数据来源
- 未声明的 API / 模型
- 评价协议之外的指标

Agent 可探索范围：

- 不同的**特征组合**
- 不同的**权重**
- 不同的**聚合方式**
- 不同的**评价策略**

且必须严格按照预先制定的 `03_agent_harness/plans/` 执行，不得擅自改变实验目标、数据划分和评价协议。

## 稳定约束

- Check-Agent 在**每轮实验前后**进行边界检查。
- 每**循环 3 轮**进行一次完整审计。
- 越界行为 → 该实验结果标记为 **INVALID**，不得进入后续优化和评价。
- 保留操作日志与失败原因；将「违规行为—触发条件—修正规则」写入 `04_memory/rules_memory/`，避免后续重复发生。

## 不可修改规则（与 Check-Agent 共享同一清单）

1. 数据划分
2. 测试集访问权限
3. 人工评价标签
4. 核心评价协议
5. 实验目标
6. Plan / 提示词 / Skills

Agent 不得通过修改 Plan、提示词、Skills 或执行策略绕过上述约束。
