# 2.3 记录与预算

## 需要保存的状态

### 第一阶段（指标组合探索）

每轮保存：

- 具体的指标组合方式
- 参数设置
- 一致性结果
- 与上一轮结果的差异
- 对应的失败样本与异常情况

### 第二阶段（困难样本与指标失效）

动态调整 AI 模仿生成数据集时，每轮保存：

- 生成数据集
- 使用的 LLM 与生成参数
- 生成结果
- 与人类诗歌的相似度报告
- 人类判断与自动评测结果的一致性变化

## 日志与记忆

- 每轮 Agent 的关键决策、反馈信息、执行日志
- 失败 / 异常 / 越界记录**不删除**，标记为 INVALID，保留原因与修正规则
- 有效结果、失败样本、违规记录分别进入：
  - `04_memory/experiment_logs/`
  - `04_memory/failures/`
  - `04_memory/rules_memory/`

## 资源预算

- **计算**：至少租赁一块 A100 80G GPU，用于模型推理、实验运行、模型微调。
- **LLM**：调用 DeepSeek-V4-Flash 等 API；按实际运行轮次、单轮实验规模、第二阶段生成数据量估算 Token 消耗。
- **总预算上限**：避免 Agent 通过无限增加实验轮次获得偶然性能提升。
