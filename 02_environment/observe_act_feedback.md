# 2.2 观察 / 行动 / 反馈

## Agent 可观察的信息

- 每一轮指标组合实验得到的**一致性值**（与人类评价分布的一致性）
- 具体的指标组合方式
- 人类评价结果及其对应的评价协议与反馈提示词
- 已提供的中文诗歌数据集及其人工标注结果
- 生成式 AI 生成的诗歌数据集及其与人类诗歌的相似度
- 与 LLM 微调/训练相关的参数、实验结果和运行日志

## 可执行的动作

- 在既定基础评测指标范围内进行不同组合
- 计算指标与人类判断之间的一致性
- 计算 AI 生成诗歌与人类诗歌之间的相似度
- 按 Plan / Skills 执行实验步骤
- 根据失败样本分析当前指标组合的失效原因
- 调整下一轮指标组合方案

## 反馈机制（三层）

### 性能反馈

每轮一致性值 vs. 预设阈值；判断是否达到进入下一阶段要求；作为下一轮调整的依据。

### 失败反馈

- 记录指标判断错误的样本
- 关注指标判断与人类判断**显著不一致**的样本
- 将代表性错误样本保存为负样本
- Agent 据此调整下一轮探索，而不是只优化总体一致性分数

### 边界反馈

- Check-Agent 检查数据访问、指标使用、Plan 执行、测试集访问
- 一旦发现越界：标记 INVALID，写入永久性记忆

## 第二阶段额外协议

在第二阶段，Agent 动态提高 AI 生成诗歌与人类诗歌之间的相似度，并持续收集困难样本与负样本。

持续比较人类判断与自动评测指标的一致性，重点观察：

- 二者是否出现**不同步的失效**
- 「指标先失效」还是「人与指标同步失效」
